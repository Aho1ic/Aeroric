## 2. 如何审阅与逐屏状态

直达地址默认打开 API 面板。可先观察四个基础项，再展开高级设置；
填写 `.invalid` 示例文本，切官方分支选择工具，再回 API 检查草稿保留。
“检测前说明”仅展开说明，不进行任何请求。
首次主动展开会聚焦并就近显示说明；普通编辑/重复点击仍保留正常滚动位置。
保存示例后可点“稍后设置”返回保留的连接，或主动载入固定模型样例，
继续预览已有的未发布配置引导。请勿在任何文本框填写真实凭据。

要看浅/深色，关闭面板，在外层审阅工具切换外观再重新打开。
切换“状态速览”会重置样例；外观/动效/透明度切换不重置。

## 3. 原生与保全要求

正式端使用 **SwiftUI＋苹果原生 Liquid Glass＋系统动画**；
分流和工具选择复用 NativeSelection/系统 Picker/Menu，折叠复用系统
DisclosureGroup，滚动使用系统 ScrollView。不手绘互斥活动背景或玻璃
thumb，不引入第三方 UI/字体/动画，不用 HTML/React/WebView 替换产品。
减少透明度/动态效果、增强对比度、焦点与辅助功能需保留并分别验证。
模式切换只改呈现，不能变更模型、权限、会话、cwd、PTY 或监督角色。

业务、凭据引用和发布经 Rust core/host 单写者及 typed client；
本稿不定义新的生产协议，不写真实配置或 Agent Home。
V3 主屏 renderer 与原有 CSS 前缀保持不变；新增 CSS 仅作用于添加面板。
原 V2/V3/V6、服务、证据、统一冻结实施包与其他终端产品工作保全。
来源18仓库、185观察＋U01＝186、20能力族/8闭环不变。
