## 1. 本次落实的设计

| 区域 | 本稿表达 | 不能推导 |
|---|---|---|
| 连接目录 | 按 API / 官方账号与原版工具分组，搜索、类型过滤、真实 radio；名称、接入方式、一个当前重点 | 不用单个“已连接”概括全部能力；切选中项不修复、不发网 |
| 连接详情 | 授权、工具与模型适配、额度、最近检测四维分区，不给每项再套大玻璃卡 | 已授权不等于模型可用；目录列出不等于推理成功 |
| 状态解释 | 分项状态、来源、时间、检测范围；失效和未知额度可从状态速览看构造例 | 未知不是零，未检测不是失败或通过；构造时间不是实际观测 |
| 保存后的衔接 | 连接保存成功才出现可选配置引导，可“稍后设置” | 不自动生成配置、不设默认、不发布、不改变运行任务 |
| 配置引导 | 明确选择 Harness、名称、模型、适用推理设置；空目录可跳过或主动载入固定样例 | 不把四个工具宣称为通用兼容；官方待授权账号不伪造模型 |
| 配置草稿 | 主动创建后可在连接引用和 Agent 配置只读页查看，标注本页草稿/未发布/适配待验证 | 不进入新建会话的配置列表，不写产品配置、不替换原默认 |
| 共享外观 | V6 的浅暖/石墨深色、圆润轮廓、青紫琥珀少量点缀；克制短动效 | 网页的层次不是 Apple Liquid Glass 的交付或验收 |

过滤无结果时详情同步为空；中文组合输入期间不重建搜索节点。
保存失败留在原表单；关闭引导不删除已存连接。配置模型使用连接范围内的
别名和上游 ID 展示，实际选中值保持稳定模型 ID，不串用其他连接的覆盖。

## 3. 如何审阅

默认进入总览。先切几个连接，观察左侧重点和右侧四维状态。
顶部状态速览可切“凭据失效”“额度未知 / 尚未检测”作对比，
也可直接进入“连接已保存 → 可选配置引导”。

完整交互路径：

1. 点击“添加连接”，只填示例名称和 HTTPS `.invalid` 地址；Key 输入禁用。
2. 可主动载入固定样例目录，再保存连接示例。
3. 引导选“稍后设置”：连接保留，不新增配置。
4. 或主动选择 Harness / 名称 / 模型 / 推理设置，创建未发布配置草稿。
5. 从连接引用查看草稿，或到 Agent 配置页选择它；新建会话不会出现该草稿。

模型/额度自动获取、检测授权与费用说明、刷新周期、账号池准入及正式
配置发布另行设计。本轮既不替用户确认默认，也不触发任何真实探测。

## 4. 原生约束与保全

正式实现仍 SwiftUI＋苹果原生 Liquid Glass，复用 NativeSelection、
系统 Picker / List / Menu、语义色和系统可访问性；不引入第三方 UI，
不把 HTML/React/WebView 用作产品前端，不手绘互斥活动底。
业务与凭据引用变更在 Rust core/host 单写者，经 typed 客户 API；
本稿新增状态函数不是批准的生产 schema 或协议。

官方工具登录与合资格开放接入仍分型，不复制订阅 token 给四工具；
独立账号不合并身份或额度；未知接收不因换账号盲重放。
本轮不申请官方注册、登录、访问 Keychain、扫描个人 Agent Home、
改权限/审批/验收标准或安装技能，不创建 VM。

原 V1–V6、历史证据、统一实施包、产品代码、政策及任务 metadata/context
保全；不 create/start 任务、建分支/worktree、commit/push/tag 或发布。
来源仍 18 仓库、185 观察＋U01＝186，20 能力族 / 8 闭环，不重复调查计数。
