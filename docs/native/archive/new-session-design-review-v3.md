## 3. 视觉与状态变化

- 输入框为 32px 圆角，窄屏 28px；保留可写面积，不变成椭圆。
  续聊占位输入框同步更圆润，但未实现续聊业务。
- 四个工具使用相同宽度、边框、背景和高度；窄屏横向滚动，不一大三小。
  使用真实 radio 的选中状态与原有图标路径，不自绘活动背景/下划线。
  图标复用 `src/assets/{chatgpt,claude,omp,deepseek}.svg`，清理为内联 path；
  仅代表当前项目既有识别资产，不声明品牌资产新增授权。
- 项目与工作目录移入「更多配置」，项目上下文仍由侧栏和面包屑体现。
  项目迁移冲突仍未定，不借移动字段实现跨项目迁移。
- 草稿分别保存 `tool` 和 `config` 的示例身份。主配置仅列当前工具配置，
  连接及允许模型由该配置绑定，不能在会话中任意拼接另一连接的模型。
- 主执行、独立审查、反思、治理分别选择工具、配置、模型、强度；
  改主配置不联动其他角色、权限、提示词或附件。
- 切换工具暂用目标工具的明示示例配置；再次点同一工具不重置配置。
  跨工具记忆规则尚未决定，此示例不是产品默认。
- custom 身份仍在更多配置中保留。选 custom 时四个胶囊均不选中，
  不错误高亮 Codex，也不发起自动探测。
- 「官方订阅」「多账号池」只在 Codex 配置里呈现**待配置、发送受阻**状态。
  不伪造 OAuth 成功、真实账号、额度或自动轮换。
