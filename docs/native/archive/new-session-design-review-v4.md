## 2. 动效、布局与拖拽：原生优先，不堆网页依赖

浏览器稿用自身 CSS Grid / Flex 和短动效表达，不新增外部布局/动画库。
页面切换220ms、悬停/按压140ms，输入/改设置不重播页面入场；
没有循环动效、光标追随或自动滚动。系统和手动减少动态均可关掉过渡。

拖拽只用于有意义的操作：

- 产品简报虚构卡片 → 输入框，加入示例引用；点击同卡片等价，
  去重，不读取真实文件，不自动发送、安装或扩权。
- 账号池手柄 → 另一个成员前，只改排序草案；
  上移/下移与撤销提供非拖拽路径，保存仍需明确操作。
- 非本页附件/成员 ID、文件/外部 URL 不转成引用或导航；
  普通文本拖放编辑保持原生文本行为。

正式产品继续 **SwiftUI＋苹果原生 Liquid Glass**。映射候选包括已有
`NativeSelection`、系统 Picker/Menu/List、Grid/Layout/ViewThatFits、
原生符号与动画、typed Transferable 拖放；不是导入网页动效或 WebView。
具体 API/工具链版本、中文字体回退和品牌资产先核对，再做实施包；
本轮不新增 Swift 包/字体许可证、不改最低系统或产品原生代码。

苹果公开设计文档于2026-10-21通过文本请求核查，未启动浏览器：

- Motion：`https://developer.apple.com/design/human-interface-guidelines/motion.md`
- Drag and drop：`https://developer.apple.com/design/human-interface-guidelines/drag-and-drop.md`
- 衬线设计：`https://developer.apple.com/documentation/swiftui/font/design/serif.md`
- typed drop：`https://developer.apple.com/documentation/swiftui/view/dropdestination%28for%3Aaction%3Aistargeted%3A%29.md`

上述用于设计依据，不证明当前源码已满足原生 API 或平台验收。
原文/获取收据在本轮临时证据 `apple-docs/`，不下载字体或 SDK。
