## 2. 动效表达与不变的状态

名称以240ms宽度展开/收拢、160ms淡入淡出，稳定顺序、不弹跳，
不反复播放整页入场。浏览器稿的工具切换保留radio与标签节点，
只局部刷新输入框及下方配置，避免替换选择器导致过渡/键盘焦点丢失。
系统和手动减少动态关闭这些过渡，增强对比/强制色保持系统可见选择态。
窄屏整组换行，极窄时组内可滚动，完整工具不变成“更多”菜单。

## 3. 正式产品必须用SwiftUI与原生Liquid Glass

本稿表达布局/标签过渡，**不能证明原生玻璃滑动已实现**。

仅封装纯文本系统分段Picker，不能把该现状写成已支持图标/动态标签。
