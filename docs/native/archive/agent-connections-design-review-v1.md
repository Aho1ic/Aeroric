不是重命名后丢失配置引用。API均未连接，官方账号均未授权；

## 4. 账号池与授权的明确边界

- 全部账号是虚构待授权引用；策略初始为“请选择策略提议”，
  不把拖拽顺序默认为优先级策略或替用户选首发默认。
- 拖动只改未存顺序；保存形成**本页草稿**，不是发布/启用。
  权重/并发等未画字段不按魔法默认执行，刷新就清空。
- 未发送、接收未知、流已开始/工具可能执行分别说明；
  没有下游输出不等于上游未接收，不因换账号自动重放。
- 官方工具登录与合资格开放接入按基础检查点分型；
  不复制/中转订阅token给四工具，不将原版登录状态当通用API Key。
- UI中“工具适配待验证”不等于供应商授权、模型权限或全旅程成功。
  API Key输入禁用；真实凭据、登录、模型/额度请求均未发生。

## 5. 后续原生实现与本轮验证边界

正式界面仍SwiftUI与苹果原生Liquid Glass，参考已有NativeSelection、
原生分栏/自适应布局与typed拖放；HTML不是产品壳。
Rust core/host负责连接、凭据引用、配置版本、路由及统计变更，
UI不构造Agent argv、不写共享业务数据、不扫描个人home。
本轮不改Swift/Rust/legacy，不创建任务或切执行状态，不交实施终端。

独立loopback只读八资源的范围已在V4 README审查；用户手动打开，
不自动开浏览器、不做输入/截图/CDP/AX，不启动App/Preview/UI/VM。
不联网测试、Keychain、CLI登录、账号池调度或真实配置发布。
原生UI验收仍 **NOT RUN / DEFERRED**。
证据定位 `/tmp/aeroric-q125-v4-location`；以最终 `validation.json`
列出的实际结果为准，内存/字符串/静态/HTTP不证明视觉或原生验收。
