## 5. 左导航与右分段：原生选择，不画假滑块

- 左侧项目/任务普通行透明、无常驻圆角卡片边框；悬停出现深色圆角
  强调，明暗共用语义角色。不是每个项目一直挂一个浅色胶囊。
- 用户要求点击后的整行加深；未来原生必须由现有
  `NativeSelectionList` / `List(selection:)`的系统选中态完成，
  不能叠自绘深色选中背景。最终深浅、系统强调色及非活动窗口状态须核对。
- **网页只呈现普通态和hover方向，持久选择仍是浏览器原生radio，
  没有声称已交付原生整行深色选中效果。**
- 文件/Git改为一个共用轨道的左右分段布局槽，标记
  `NativeSegmentedPicker`原生接线。网页原生radio只用于试切换；
  **没有真正苹果分段滑块或滑动动画**，不手绘CSS选中块冒充系统。
- 产品使用原生分段选择、Apple Liquid Glass交互层，并尊重减少透明度、
  增强对比、减少动态。文件/代码/diff仍用稳定语义阅读底，不整篇叠玻璃。
  **本稿没有原生材质或滑块验收证据**，不拿CSS blur作替代。

上述浏览器能力边界是显式差异，不以“看起来像”销账；若用户需要核对
实际系统材质/滑块，须另行授权和审查原生查看范围，不能绕过UI暂停。
