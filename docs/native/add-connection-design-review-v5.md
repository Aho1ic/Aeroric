## 4. 原生还原约束，不是本轮实施

- **SwiftUI + Apple 原生 Liquid Glass**，不用 React/WebView 或第三方
  布局、动效、字体库替代。浏览器的层次和短入场动效不是苹果材质/动画证明。
- 互斥项：`Picker`、`List(selection:)` / `Table(selection:)`、`Menu`，
  复用 `Design/NativeSelection.swift`；开关用 `Toggle`，
  折叠用 `DisclosureGroup`。不以 CSS 的 radio 外观或手画活动滑块作为产品实现。
- 单独图标按钮不套圆形边框；输入和组合胶囊保持圆润，灰黑深色保持柔和层次。
  尊重减少动态/透明度、增强对比度；隐藏可视滚动条但保留滚动。
- 连接与版本化模型目录由 Rust core/host 单 writer 管理，SwiftUI 只收
  typed 投影、发命令；秘密、OAuth/原版工具适配与网络不落到界面状态里。
- 配置创建不等于将凭据发布到 CLI Home。账号许可、协议兼容、撤销和
  发送前安全校验仍独立；不把原型中的构造兼容表发布为能力事实。
- 页面批准后还需单独工程交接；不将本稿 JSON/JS fixture 当作生产 schema，
  不因此启动原生实施、真实登录或付费请求。
