## 4. 全局原生还原契约

### 4.1 连续底座与材质

- 复用`NativePanelFoundation`、`GlassPanel`、`NativeMaterial`。
  面板间留白属于同一连续底座，不出现高反差三角口袋、不贴补丁。
- 操作/导航层用Apple原生Liquid Glass；正文、表单内容、diff、编辑器、
  终端使用稳定语义阅读底色，不整窗/整篇正文反复叠`glassEffect`。
- 深色主结构为**灰黑/石墨分层**，不能整页泛蓝。浅色为柔和暖白/
  淡青关系；蓝/青/紫/琥珀仅用于功能和状态的小面积语义强调。
- 颜色接入现有`Color.ds*`语义角色与受控样式。不要把CSS hex抄进叶子
  View、从截图采RGB或用透明色假装原生玻璃。现有语义角色表达不足，
  单列最小扩展及调用方影响交监工，不绕开token锁定测试。
- `glass/classic`与`native/advanced`保持独立；系统减少透明度、
  增强对比、减少动态必须被实际View消费，不只是存在策略函数。

### 4.2 控件与图标

- 小型自有文字按钮、短输入/标签、能力项承接胶囊；大容器使用本屏
  已审圆角，不将大段内容裁成药丸。
- 单独图标按钮默认只有图标，无常驻圆形边框/玻璃托盘；保留
  `Button`、help、禁用、命中范围、hover及原生键盘焦点。
- 功能图标优先SF Symbols；四Harness使用已审稿对应的矢量标识，
  不替换成四个任意系统图标或单字母。可复用/转换本地现有矢量为
  原生asset，核对来源及许可；不下载字体、图标包或安装绘图库。
- 邻接互斥导航/页签/选择使用共享`NativeSelection.swift`中的系统
  `Picker` / `List(selection:)` / `Menu`；不手绘active背景、下划线
  或跟随selection的胶囊。独立能力开关继续独立`Toggle`。
- 下拉箭头轻、细、与文字相称，采用系统菜单指示；不要把网页chevron
  SVG覆盖在原生select/Menu上，不保留双箭头，不遮住点击/焦点。
- 装饰轨道可用SwiftUI `Shape/Path`或现有本地矢量，不加载网页，
  不引入Canvas/WebView动画层。纯装饰不抢焦点、不制造无障碍噪声。

### 4.3 窗口、字号与可达性

- 保留标准NSWindow、交通灯、拖动、resize、全屏。网页外角
  24/34px不是可直接设置的系统窗口半径，不用私有API/swizzling/
  无边框窗口追像素。
- 正文/导航沿已确认14pt、次级11–12pt、普通标题18pt；
  V6艺术标题是明确局部例外，不把全软件正文改成宋体。
  网页小号注释不授权牺牲可读性。
- 初始1260×860及左右320pt只适用于无恢复几何的初始呈现，
  不覆盖用户已有窗口。右检查器默认关闭；既有显式开启选择保留。
- 400×600是既有适配目标，不是本批次可以无证据宣布支持的能力；
  不静默降低当前正式窗口下限。窄布局冲突要实算并登记。
- 不裁掉光标、IME、滚动条或焦点；动态文字/长标签/路径须能读完。
  AX identifier放叶子、完整名称可读，不用容器吞掉子控件。
- 动画采用SwiftUI/苹果系统行为，短促克制，减少动态时取消非必要
  展开/入场/位移动画；不能因外观动画重建任务/PTY。
