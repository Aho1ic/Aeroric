## 2. 页面状态与影响面

侧栏从多行select换成同组真实radio，统一全局页面/项目草稿/项目会话
的互斥语义。每个选项有稳定ID、可读名称、可见系统圆点与整行点击目标；
当前项同时标记`aria-current`。此处radio是浏览器审阅辅助，不是正式端要求。
hover不改当前页；互斥状态仍来自现有view/project/task模型，不另建导航状态。
切页重建后恢复侧栏scrollTop，并对恢复焦点的行使用系统nearest滚动，
不做平滑强制动画；保留工作区滚动规则，不将两处滚动混用。

项目下拉只显示名称，实际option value仍为项目ID；去掉路径tooltip。
选择另一个项目仍产生“预选但未迁移”提示，不覆盖其他草稿；
取消提议回原归属。具体路径没有删除，也不读取真实项目目录。

Harness选择继续保留四个原radio/label节点，切换只更新输入区配置；
重复选择不重置配置，提示词/附件/权限/监督绑定不被联动改变。
custom不冒充四个工具；配方版本/方案差异应用/实际文件要求/依赖受阻/
失败草稿保留/接收未知先核实不重发/跨页恢复等规则不变。

账号V1组件、状态、CSS及fixture逐字保留，没有新增账号业务。
**共享外观确实改变账号页**：灰黑语义色、全部dropdown箭头和侧栏。
不能把这种字节沿用写成“账号界面不变”；账号各面仍待视觉审批。
工具库占位仍不是工具库的最终审批稿，本轮不借样式修改悄悄增功能。

## 3. 原生Liquid Glass与系统选择：不能用网页假装交付

### 3.1 主路径与经审查候选

正式端优先复用`macos/AeroricKit/Sources/AeroricUI/Design/NativeSelection.swift`，
增加系统Picker的图标标签变体，系统负责选择态及原生材料/动画。
现有封装只有Text标签；本轮**没有实现图标变体、运行组件或验证thumb**。
`Label`/可变标签不保证在每个平台segmented样式中图文同显。

若标准Picker无法同时保留图文和完整名称，**待评审的具体候选**是
SwiftUI `NSViewRepresentable`桥接苹果系统`NSSegmentedControl`，
仍集中在NativeSelection，不向叶子视图散落自制选择器：

- 用系统`.selectOne`维护互斥选择及高亮，固定工具索引和顺序；
- 各项保留图像，当前项设置全名、其余标题留空；
- 自动尺寸`setWidth(0, forSegment:)`与`.fit`分配是核验候选；
- 系统`.automatic`决定外观，不指定/伪造某个透明thumb；
- 不重写cell绘制，不叠自制选中底，不引入第三方。

**以上是可查的API组合候选，不是已验证图文/动画方案。**
Apple概览与具体setter不足以保证图片＋文字一定同时渲染。
公开SDK没有`NSSegmentedControl.Style.slider`，不能编造这一接口。
`.capsule`也不是“启用Liquid Glass滑块”的保证。
`glassEffect`/`glassEffectID`可做原生材料/几何过渡，
但不是获取或配置系统Picker选中thumb的API；不能借此绕过选择规则。

若真实系统能力无法满足视觉稿，需把约束带回用户讨论；
例如“系统图标选择＋旁边当前全名”或“全名系统Picker”都属于
**未获批准的回退**，不在实现时静默换成其中一个。

### 3.2 侧栏、胶囊与辅助功能

正式导航仍用`NativeSelectionList`/`List(selection:)`及系统sidebar风格。
行内容可调`listRowInsets`、`defaultMinListRowHeight`、适用的separator，
但这些不承诺控制系统高亮背景的精确圆角。
macOS公开接口的`listRowSpacing`不可用，不能照搬iOS方案。
`contentShape`/`containerShape`/`clipShape`也不保证能把系统高亮改成999px。
不得为复刻网页轮廓而补手绘选中背景。

组合能力正式仍为独立`Toggle`；不将checkbox模式写成互斥Picker。
菜单用系统`Menu`/Picker的原生指示，**不把网页chevron SVG搬进产品**；
保留系统焦点、键盘、VoiceOver，不用图片按钮重造菜单。

macOS 26的Liquid Glass是availability-gated原生增强，不提高原最低系统；
旧系统/减少透明度保留苹果原生材料/不透明回退。
减少动态、增强对比、强制色不能为追求透明而丢失可见选择态。
“更扁”指视觉密度，不授权压缩iOS触控命中目标或裁剪动态字体。

### 3.3 核对证据与待验证清单
