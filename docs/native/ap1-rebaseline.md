## 一、分母与证据层级定义 (Denominator & Evidence Hierarchy)

为彻底杜绝“旧 accepted、方法注册数、编译通过或单元测试绿灯冒充新产品验收”的漂移，AP1 确立以下严格分层的分母定义：

| 层级 | 分母类型 | 判定范围与指标 | 适用阶段与门禁边界 | 严禁反模式 |
|---|---|---|---|---|
| **L1** | **Capability (能力声明)** | 协议模型、`requires_capability`、DTO 往返字段定义 | 协议与类型设计 (AP2/AP5) | **严禁**将类型定义存在或反序列化成功当作能力已支持。 |
| **L2** | **Method Registration (方法注册)** | `command-map.json` / host set 中的 660 条注册位 | 接口路由接入 (AP2) | **严禁**将补齐 660 方法数或返回空对象当作功能实现。 |
| **L3** | **Actual Forwarding (实际转发/执行)** | 无头 Host 真实生命周期、UDS 字节流、无 NoStreams、无假 capability | 核心宿主闭环 (AP2/AP3) | **严禁**使用 fake/mock 冒充外部真实集成。 |
| **L4** | **Native User Journey (用户旅程)** | 原生 SwiftUI 界面可见、可交互、任务流转、PTY/审批/终端/文件真实响应 | 双端前端接线 (AP4/AP5) | **严禁**将“目录里有 View 文件”或“窗口可启动”当作旅程通过。 |
| **L5** | **Store Release Gate (商店发布门禁)** | 沙箱强隔离实测通过、嵌套签名校验、两端 App Store 真实审核通过 | 全量发布验收 (AP8/AP9) | **严禁**以 ad-hoc 签名或未审核状态声称交付完成。 |

## 二、F01–F26 能力组逐条重定基线表 (Feature Group Rebaseline)

依据 Apple-only 基线，对原有 26 个功能组逐条核定其生命周期形态（保留、替代或退休），明确 Mac 与 iOS 伴随端的承接阶段及主验收标准：

| ID | 历史功能名称 | 处置形态 | Mac 首发承接边界 | iOS 首发伴随边界 | 主验收阶段 | 验收与门禁要求 |
|---|---|---|---|---|---|---|
| **F01** | 项目管理 | **保留** | 原生 SwiftUI 项目列表、分组、固定、排序、最近访问 | 查看与切换项目上下文 | AP2 / AP4 / AP5 | 真实单写者写入，多端状态同步 |
| **F02** | 任务管理 | **保留** | 原生任务创建、排队、生命周期、归档、取消/恢复 | 完整任务远控与状态流转 | AP2 / AP4 / AP5 | 任务终态不复活，状态机确定性 |
| **F03** | Agent 运行时与启动 | **替代** | **纯内嵌 Runtime / 内置协议与 helper 承接** (摒弃外部 npm/brew CLI 路径) | 既有 Agent/模型/参数选择 | AP2 / AP4 / AP5 | App Sandbox 下合法 spawn，不依赖外部未授权路径 |
| **F04** | 终端与 PTY | **保留** | 原生 PTY 字节流、IME 输入、窗口 resize、输入租约 | 原生终端流式呈现与同一宿主租约 | AP2 / AP4 / AP5 | `controlling_tty(false)` 沙箱兼容，无 ANSI 伪造 |
| **F05** | 会话管理 | **保留** | 托管会话发现、分页、导出、恢复、Token 用量 | 会话与任务查看、恢复 | AP2 / AP4 / AP5 | 会话文件懒加载与沙箱路径兼容 |
| **F06** | 交互与审批 | **保留** | DSH / 四族审批瀑布、消息、问题回答、附件排队 | 实时审批接收与回复 | AP2 / AP4 / AP5 | 严格安全审批回路，离线不执行过时审批 |
| **F07** | 文件与编辑器 | **保留** | 原生文件树、搜索替换、冲突解决、本地历史 | 既有文件查看与轻量编辑 | AP2 / AP4 / AP5 | Security-Scoped Bookmarks 持久化授权 |
| **F08** | IDE 与工具 | **保留** | 语言服务 (LSP)、诊断、运行/测试、DAP 调试 | 不要求全量移动端 IDE/DAP | AP2 / AP4 | Mac 平台沙箱内独立 LSP 适配 |
| **F09** | Git 版本控制 | **替代** | **内嵌独立 Git/libgit2** (替代系统 xcrun git) | Git 状态查看与移动端提交/暂存 | AP2 / AP4 / AP5 | 彻底规避 xcrun 沙箱拦截报错 |
| **F10** | Worktree 管理 | **保留** | Worktree 生命周期、任务关联 | 关联状态查看，不复制管理 UI | AP2 / AP4 | 目录授权继承与并发隔离 |
| **F11** | SSH / SFTP 远端 | **保留** | Mac 宿主直接接管 SSH/SFTP (关账 G43) | 经 Mac 接入，手机不直连服务器 | AP2 / AP4 / AP5 | 平台凭据由 Mac Keychain 安全管理 |
| **F12** | **WSL 功能** | **退休 (RETIRED)** | **功能彻底退休**；旧记录保留并安全拒绝，严禁误认作本地路径 | 不提供 WSL 功能 | AP1 / AP8 / AP10 | 不计入新增交付，删除未覆盖代码不计为覆盖率上涨 |
| **F13** | 基础设施管理 | **保留** | 本地 Docker/Conda/端口发现与状态 | 不要求移动端全量管理网格 | AP2 / AP4 | 沙箱内受控检测，安全优雅降级 |
| **F14** | 数据库工作区 (DBX) | **保留** | SQL/Redis/Mongo 结构、数据表格、生产确认 | 不要求移动端完整数据网格 | AP2 / AP4 | 动态库沙箱内安全加载 |
| **F15** | 笔记与附件 | **保留** | 原生 Quick Notes、附件、双链、标签 | 不要求移动端全量笔记网格 | AP2 / AP4 | 容器内安全存储 |
| **F16** | 笔记同步与 RAG | **保留** | 存储后端同步、RAG 索引与凭据保护 | 纯伴随查阅，不新增全量 RAG 工作区 | AP2 / AP4 | 本地知识库检索与权限隔离 |
| **F17** | 扩展与 Provider | **保留** | Skills、MCP 协议、Hooks、Provider 路由 | 任务相关关联设置 | AP2 / AP4 / AP5 | 容器内 Hook 执行与隔离环境 |
| **F18** | 远程与配对 | **保留** | 认证 UDS、E2EE 直连、自托管 Relay 桥接 | 原生 iOS 直连 / 自托管 Relay 伴随 | AP2 / AP5 / AP6 | 手机不直连计算服务器，Mac 权威执行 |
| **F19** | 系统与维护 | **保留** | 通知、用量统计、缓存清理、权限核验 | 任务状态查看、后台推送接收 | AP3 / AP4 / AP6 / AP9 | 退出旧自动更新器，走 App Store 更新 |
| **F20** | 会话高级控制 | **保留** | Plan/Compact/Fork/Revert 预览确认 | 相关会话控制与状态查阅 | AP7 / AP5 | 原 Phase 9 首发硬目标，入队权限固定 |
| **F21** | 内存与任务树 | **保留** | Memory/Checkpoint、Task Tree、Goal/Subagent | 任务树查看与会话状态 | AP7 / AP5 | 跨会话节点隔离，终态不复活 |
| **F22** | 工作流与蒸馏 | **保留** | Workflow/有界重试、Dream/Distill 离线总结 | 运行状态查看与确认 | AP7 / AP5 | 有副作用操作绝不自动重试，Dream 默认关闭 |
| **F23** | 认证与多模态交互 | **保留** | ACP / OAuth / Sandbox / Browser / Voice | 交互边界显式呈现 | AP7 / AP5 | 语音先草稿后提交，OAuth 凭据原所有者 |
| **F24** | 模式无损切换 | **保留** | Native / Advanced 呈现模式无缝切换 | 对应原生/终端呈现 | AP4 / AP5 | 不杀进程、不换 Session、不重置 PTY 租约 |
| **F25** | 系统质感与体验 | **保留** | 原生 Liquid Glass (macOS 26+)、多窗口、a11y | 原生 iOS/iPadOS 触控、键盘与布局 | AP4 / AP5 / AP8 | 系统选择控件，减少透明度/动态效果支持 |
| **F26** | 无头核心与后台 | **保留** | 无头 host/CLI、显式后台 opt-in、停止入口 | 手机感知 Mac 在线/离线状态 | AP2 / AP3 | 不开启不驻留，不自动重复 spawn |

## 三、旧任务体系 (P1–P10) 到新阶段 (AP0–AP10) 映射矩阵

旧计划在执行至 P8-05（切片111 Conda 改造）时冻结并转向 Apple-only 架构。旧阶段的历史结果保留为证据输入，新产品交付以 AP0–AP10 为唯一口径：

| 旧任务范围 | 历史状态记录 | 新 AP 阶段承接 | 承接责任与实施边界 |
|---|---|---|---|
| **P1 (P1-01 ~ P1-05)** | 历史 accepted (骨架与规范) | **AP1** | 规范重定基线，旧 carrier 保持工具兼容，不当作新交付。 |
| **P2 (P2-01 ~ P2-05)** | 历史 accepted (协议与存储) | **AP2 / AP3** | 协议 v1 与存储单写者机制复用，沙箱文件授权移交 AP3。 |
| **P3 (P3-01 ~ P3-07)** | 历史 accepted (Core / Host / CLI) | **AP2** | 复用无头 Host 与 CLI 骨架，承接四族真正执行与事件流。 |
| **P4 (P4-01 ~ P4-04)** | 历史 accepted (Mac 原生脚手架) | **AP4** | 原生 SwiftUI 项目工程，升级 Liquid Glass 与最新 SDK。 |
| **P5 (P5-01 ~ P5-05)** | 历史 accepted (终端与任务 UI) | **AP4** | 原生终端、任务与会话接入，绑定真实认证 UDS。 |
| **P6 (P6-01 ~ P6-05)** | 历史 accepted (文件/Git/IDE) | **AP2 / AP4** | 文件与 Git 接入，适配安全书签与独立 Git runtime。 |
| **P7 (P7-01 ~ P7-06)** | 历史 accepted (连接/基础设施/DBX) | **AP2 / AP4** | P7-02 WSL 退休；SSH/SFTP 移交 Mac 宿主；DBX 动态库沙箱内加载。 |
| **P8-01 ~ P8-04** | 历史 accepted (扩展/Provider/Remote/维护) | **AP2 / AP5 / AP6** | Remote Bridge 完整闭环；退出旧自动更新器。 |
| **P8-05** | 部分提交 (切片102-110, 111 WIP) | **AP2** | 保护 Conda 等已有 WIP，剩余宿主接管缺口统归 AP2 闭环，不续跑旧切片112。 |
| **P9 (P9-01 ~ P9-04)** | 历史 pending (Phase 9 高级能力) | **AP7** | 原 Phase 9 全部高级能力列入首发硬目标，逐项跑通真实上游。 |
| **P10 (P10-01 ~ P10-05)** | 历史 pending (全量验收与发布) | **AP8 / AP9 / AP10** | 分解为：AP8 全量用户旅程/迁移演练 $\to$ AP9 双端商店构建与真实审核 $\to$ AP10 旧前端与平台彻底清退。 |

## 四、历史 Gap 清单 (G01–G42 及 G43) 承接对账

所有 42 个历史功能缺口及新增 G43 均有明确承接阶段，严禁在未获实证前销账：

| 缺口区间 | 缺口内容概述 | 目标承接 AP 阶段 | 销账门槛与条件 |
|---|---|---|---|
| **G01 ~ G05** | 任务管理、归档、交互流转 | **AP2 / AP4** | 无头 Host 状态机闭环并在 SwiftUI 真实操作验证。 |
| **G06 ~ G10** | 会话持久化、Token 用量、搜索 | **AP2 / AP4** | 托管沙箱目录真实读写，搜索防抖与高亮成立。 |
| **G11 ~ G16** | 文件树、编辑器、冲突合并、历史 | **AP2 / AP4** | Security-Scoped Bookmarks 持久化读写成立。 |
| **G17 ~ G22** | Git 操作、Worktree 隔离、提交 | **AP2 / AP4** | 独立内嵌 Git 运行无误，不受 xcrun 沙箱拦截。 |
| **G23 ~ G28** | LSP 诊断、DAP 调试、基础设施 | **AP2 / AP4** | 语言服务与调试器在沙箱限制下正常通信。 |
| **G29 ~ G35** | DBX 数据库连接、动态库、查询 | **AP2 / AP4** | SQLite / Redis / Mongo 连接与只读/写入确认生效。 |
| **G36 ~ G42** | 笔记、同步、RAG 知识库检索 | **AP2 / AP4** | 向量数据库与本地笔记沙箱持久化闭环。 |
| **G43** | **平台凭据与远端 SSH/SFTP 宿主适配** | **AP2** | **由 Mac 宿主平台直接接管**，不得永久残留在待删除的 Tauri 中；在宿主平台跑通真实 SSH 运行证据后方可销账。 |

## 五、平台退出与保留边界对照表

| 维度 | 彻底退出 (Retired) | 完整保留并支持 (Retained) |
|---|---|---|
| **客户端平台** | Windows 桌面客户端、Linux 桌面客户端、Android 客户端、旧 Tauri/React 桌面、旧 Expo 移动端 | macOS 原生客户端 (SwiftUI / Apple Silicon + Intel macOS 26)、iOS/iPadOS 原生客户端 (SwiftUI) |
| **对端与远端系统** | WSL (Windows Subsystem for Linux) | Linux/Unix SSH 服务器、macOS SSH 服务器、Windows SSH 服务器 (保留远端工作区能力) |
| **网络与中继服务** | 官方默认云端中继 (不提供) | 独立自托管 Linux Relay、局域网直连、E2EE 端到端加密通道 |
| **权限与安全模式** | 宿主全局无沙箱执行、依赖系统 PATH 外部可执行文件 | macOS App Sandbox 强隔离、Security-Scoped Bookmarks 显式授权、Keychain 凭据加密 |
