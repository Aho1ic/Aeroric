# Agent Note: 设置界面重新设计（方案）

Status: proposed

2026-11-24 用户通过了这个方案。阶段 1，以及阶段 2–5 里不用改宿主的部分已实现，见 [设置界面重新设计：分组、搜索、平铺行、新页面](../../implemented/feature/2026-11-24-settings-redesign-first-cut.md)。

## Problem

用户 2026-11-23 要求优化设置界面，并给了 32 张参考截图（`~/Desktop/Snapzy/`）。
- 31 张是 ChatGPT / Codex 桌面端的设置窗口；
- 1 张是一个邮件客户端，和设置无关，没有参考。

现在的设置窗口（`SettingsRootView`，`main@083097c4`）：
- **导航：** 左栏是 8 个平铺的页：通用、外观、Agents、参考代码库、导入、连接、旧版 Agent 清理、关于。没有分组，也不能搜索。
- **页面：** 每页一个大标题，下面是带边框的卡片（`SettingsCard`），卡片里一行是标题、灰色说明、右侧控件。页面没有副标题，标题旁也放不了操作按钮。
- **散在别处的设置：**
  - 主窗口侧栏有“Agent 配置”页（连接、号池、路由、升级）；
  - “远控”页（手机配对、设备、审计）在侧栏标着“即将支持”，`RemoteAccessSettingsView` 已经写好，没有入口；
  - 记忆整理、按意思找（embedding）的开关在记忆页；
  - 技能目录在侧栏“扩展”页。
- **缺的：** 通知、键盘快捷键、存储占用、Git 与工作副本，这几类设置现在都没有页面。

## Proposal

先定方案，不动代码；用户确认后按下面的阶段做。

### 参考截图里值得照搬的做法

1. **左栏：**
   - 顶上一个搜索框；
   - 分组，组名用灰色小字（App、Data & Privacy、集成、编码）；
   - 每行一个图标加名字，选中时是胶囊底色。Aeroric 的 `HoverCapsuleRow` 已经是这个样子。
2. **页头：**
   - 大标题，下面一行灰色副标题，说这页管什么；
   - 右上角放这页的操作，比如“浏览目录”“添加”“刷新”。
3. **行：**
   - 左边标题加灰色说明，右边是控件：开关、胶囊下拉、分段按钮或按钮；
   - 行之间用细线隔开；
   - 一组行上面有灰色小节标题，组本身不画边框。这比现在“每组一张有边框的卡片”轻。
4. **页内标签：**
   - 标签带数量，比如“插件 3 · 应用 10 · MCP 2 · 技能 64 · 市场 2”；
   - 右边是这个标签自己的搜索框。
5. **实体列表：** 每行有图标、名字、一行说明，右侧是开关和“›”，点进去看详情。
6. **危险操作：** 用红字（删除、全部清除），点了要确认。
7. **外观：**
   - 主题用三个图标的分段按钮（跟随系统、浅色、深色）；
   - 还有对比度、字体、字号；
   - 浅色和深色各有一套预设，可以改背景、前景、强调色（色块加十六进制），下面有一段代码预览。
8. **存储：** 一条占用条加图例（聊天、工作树、其他），下面是明细和各目录的大小，每项有“管理”或“浏览”。
9. **钩子：**
   - 按来源分组：用户配置、插件、各项目；
   - 每组写“N 个钩子 · M 个问题 · K 项待审核”，点进去看明细。
10. **连接：** 页内标签分“控制这台 Mac”“控制其他设备”“SSH”。

不照搬的：
- 账户、家长控制、账单：Aeroric 没有账户；
- 语音、迷你界面、应用快照、云电脑：Aeroric 没有这些功能。

### Aeroric 的新结构

左栏分五组。括号里写这一页放什么，以及现在放在哪：

- **应用**
  - **通用：** 引导、菜单栏、电源、空闲释放、重启后续跑、侧栏显示（现“通用”页）。
  - **外观：**
    - 现“外观”页的主题、材质、字号、会话中文字体；
    - 新增：对比度（默认 / 高对比度）、浅色和深色的配色预设、代码预览。
  - **通知（新）：** 回合完成、需要审批、定时任务结果、委派回报。每项选“系统通知 / 只在应用内 / 不通知”，另有提示音开关。
  - **键盘快捷键（新）：** 先列出现有快捷键（⌘N、⌘O、⌘K、⌘↩、⌥↩ 等）；能不能改另议。
- **Agents**
  - **新会话：**
    - 默认 Harness；
    - 说明每个项目会记住上次选的配置、模型、思考强度、权限（2026-11-24 已实现）。
  - **Agent 配置：** 在这里放入口卡，写现有连接和配置的数量，“打开 Agent 配置”跳到主窗口那页。那页太大，不搬进设置。
  - **求助专家**（现“Agents”页里）。
  - **Agent 升级**（现在在 Agent 配置页里；设置里只放入口和“有 N 个可升级”）。
  - **旧版 Agent 清理**（现有，没有可清的时候隐藏）。
- **数据与隐私**
  - **导入**（现有）。
  - **存储（新）：**
    - 数据目录的占用条，分会话、记忆与索引、参考代码库索引、工作副本、日志；
    - 每项写大小，并有“在访达中显示”。
    - 需要宿主新加一个只读方法，算各目录大小。
  - **记忆与整理：** 后台整理、按意思找（embedding）的开关，从记忆页的设置部分搬入口过来。记忆页保留原样。
  - **诊断：** 导出诊断报告（现在在“关于”里）。
- **集成**
  - **技能与扩展：** 页内标签“技能 N · MCP N · Hook N · 插件 N”。技能沿用 `SkillCatalogPage`；MCP、Hook、插件先写“尚未提供”，和侧栏“扩展”页现在的说法一致。
  - **参考代码库**（现有）。
  - **远程与手机：**
    - 把写好的 `RemoteAccessSettingsView` 放进来；
    - 页内标签“这台 Mac（启用、二维码）· 已配对设备 · 审计 · Relay”；
    - 远程写文件的开关（`allow_file_writes`）在这里给出界面，默认关，打开要确认。
  - **连接：** 宿主连接状态、协议版本（现“连接”页）。
- **编码**
  - **Git：** 委派和审查开工作副本时的分支前缀、提交说明的附加指引。需要宿主有对应设置，先列出、标“即将支持”，不放没作用的控件。
  - **工作副本：** 工作副本根目录、自动清理、保留数量，以及现有工作副本的列表。也需要宿主支持，同上。
- **关于**（不分组，放最底下）：版本、构建号、环境。

### 视觉规范

- **窗口：** 最小 860×560。左栏 220pt；内容列最宽 680pt，居中。
- **页头：** 标题 22pt 半粗，副标题 13pt 灰；操作按钮在右上角，用胶囊样式。
- **小节：** 标题 12pt 灰色。行与行之间用细线，组本身不画边框和底色。现在的 `SettingsCard` 改成这种“平铺组”，`SettingsRow` 的接口不变，各页不用改调用。
- **控件：**
  - 开关用强调色；
  - 下拉用和新建会话一样的胶囊（`ComposerPicker` 的样子）；
  - 二选一或三选一用分段胶囊。
- **搜索：**
  - 匹配页名、行标题和说明；
  - 左栏只留有命中的页，点进去滚到那一行并闪一下底色；
  - 没有命中时写“没有找到”。
- **跳转：** `settings.show` 可以带页面 id 和行 id，别处的“去设置”链接直接落到那一行。

### 阶段

1. **骨架：**
   - 左栏分组、搜索、页头和副标题、平铺组；
   - 现有内容按上面的结构重新归页，不改任何行为；
   - 远控页放进“集成 › 远程与手机”，主窗口侧栏的“远控”去掉。
2. **外观与通知：**
   - 对比度、配色预设、代码预览；
   - 通知页接到现有的系统通知代码；
   - 快捷键页只读。
3. **数据与隐私：**
   - 存储页，宿主加一个只读方法；
   - 诊断导出搬过来。
4. **集成：**
   - 技能与扩展用页内标签，接上技能目录；
   - 远程写文件开关加确认。
5. **编码：**
   - Git、工作副本，宿主先有设置再出界面。

## Alternatives considered

**照搬参考截图的全部分类。** 没选：账户、语音、云电脑这些 Aeroric 没有，放进来只会出现一堆“即将支持”。

**把 Agent 配置页整个搬进设置。** 没选：那页有连接、号池、路由、升级四块，内容多、改得勤，放在主窗口里更好用。设置里只放入口和数量。

**保留带边框的卡片。** 没选：参考截图里行与行之间只用细线，页面更轻。Aeroric 设置页的卡片多了以后，一屏全是框。

## Acceptance criteria

阶段 1 做完时：
- 左栏按“应用 / Agents / 数据与隐私 / 集成 / 编码 / 关于”分组，每页有标题和一行副标题；
- 搜索“睡眠”能找到“运行任务时阻止 Mac 睡眠”这一行，点进去滚到它并闪一下；
- 现有每一项设置都还在，改了照样生效，没有一项丢失或重复；
- 远控页能从“集成 › 远程与手机”打开，主窗口侧栏里没有“即将支持”的远控；
- 浅色、深色下各页都没有边框卡片，行与行之间是细线；窄到最小宽度时没有横向滚动。

## Risks

- 改 `SettingsCard` 会同时改所有设置页的样子，漏看的一页可能挤或错位，要整体目检；
- 搜索靠行标题和说明的文字匹配，文字改了搜索结果也跟着变，要有测试盯住常用词；
- 远控页进入设置后就能打开远程访问，入口变显眼了，打开时要有明确的说明，远程写文件默认关、打开要确认；
- 存储页算目录大小可能慢（工作副本、索引很大），宿主方法要放后台、有上限，页面先显示“正在计算”。

## Consequences

- **收益：**
  - 散在各处的设置有了一个地方，能搜；
  - 远控页有了入口；
  - 每页说明它管什么。
- **代价：**
  - 阶段 1 要改 `SettingsRootView` 和 `SettingsCard`，所有设置页的外观都会变，需要整体目检一次；
  - 阶段 3 和 5 要先加宿主方法。
- **待用户决定：**
  - 阶段 1 是否照这个结构做；
  - 通知、快捷键要不要在阶段 2 做；
  - 远程写文件的开关要不要在设置里给出界面。
