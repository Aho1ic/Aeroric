# Agent Note: 逐处审查（R2-2）：按段接受、拒绝、评论，三种对比与“已看”

Status: implemented

## Problem

R2-1 只能整轮接受或撤销。一轮改了好几处，用户想留下一部分、退回一部分，或者对某一处提意见，都做不到。用户也看不出“我上次看过以后又改了什么”。

## Decision

- core `change_review.rs`：
  - 对比两端快照，结果按文件和段（hunk）拆开。
  - 段的 id 取路径、段头和正文的 FNV-1a 哈希。只要这一段内容不变，结论就一直留着，存放在 `<data>/change-review/<task>.json`。
- 三种对比：
  - 本轮：用 R2-1 的两份快照。
  - 自上次已看：从上次点“已看”时的快照（`refs/aeroric/seen/<task>`，只保留最近一次）比到现在的工作区。
  - 整个会话：从会话第一轮开始前的快照比到现在的工作区。
  - 现在的工作区用临时 index 拍快照，不动真实的 index。
- 接受：只做标记。一轮里的段全部接受后，这一轮自动变成“已接受”。
- 拒绝：把这一段单独做成 patch，用 `git apply -R` 反向应用，不加 `--index`，所以只改工作区。应用不上时标为“已过期，无法单独拒绝”，不强行改。拒绝成功后，下一条消息会提醒 Agent“不要再按原样改回来”。二进制文件只能整轮撤销。
- 评论：写下后先存着，点“发给 Agent”时把所有评论合成一条用户消息，每条写成 `文件:行号 — 意见`。这条消息走投递队列，并且等当前这一轮结束后再发。
- RPC：`changes.diff`、`changes.accept`、`changes.reject`、`changes.comment`、`changes.sendComments`、`changes.markSeen`。`turns.list` 里每一轮都带上“已拒绝 N 处”。
- 界面：
  - 右侧面板新增“改动”页：三种对比用胶囊切换，有“标为已看”，有“N 条评论待发送 · 发给 Agent”。
  - 改动以文件卡片列出，每个文件可以“全部接受 / 全部拒绝”。每一段带行号，增删行用绿红淡底标出，并有“接受 / 拒绝 / 评论”。
  - 超过 400 行的文件默认折叠。
  - 轮标题上新增“查看改动”，点了跳到这一轮；有拒绝时显示“已拒绝 N 处”。

- 目检补充：
  - 在“改动”页接受或拒绝后，会发出 `aeroricTurnsChanged` 通知，对话里的轮标记（例如“已拒绝 N 处”）马上刷新，不用等下一轮结束。
  - 文件卡片里，文件名单独占一行，过长时省略开头保留结尾；段标题只显示行号范围，完整内容放在悬停提示里。面板窄时也不会把文件名截掉。

## Alternatives considered

- **用 `git apply -R --index` 或 `git checkout -p`**：会改动真实的 index。
- **段 id 用行号**：之前的行一有增减就对不上了。用内容哈希，内容变了就自然算作一段新的、还没处理的改动。
- **每写一条评论就立刻发给 Agent**：会把一轮的意见拆成好几条消息，Agent 要来回改好几次。

## Consequences

- 内容变了的段会被当成新段，之前在它上面做的接受或评论不再显示。旧记录还留在文件里，但不再关联到任何段。
- “自上次已看”只记最近一次，看不到更早的历史。
- 右侧面板多了“改动”页后共 5 个页签，窄面板放不下。页签条改用 ViewThatFits：放得下时全部显示图标加文字，放不下时只显示图标，选中项带文字，悬停显示名称。
- 页签条随后改为铺满整行、各页签平分宽度（只显示图标时右侧不再留出一大块空白）。同时右栏底色改用左侧栏的深色，左侧两个角改为圆角并加细边；拖动条不再画直线，免得这条直线越过圆角。
- 右栏页签条去掉磨砂玻璃（玻璃显得太亮），滑块改为 recessed 样式：轨道比面板底色更深，选中的胶囊稍亮。中间一栏顶部的系统工具栏背景（macOS 26+ 画的浅色带，悬停会变色，左端还露出一条暗缝）用 `toolbarBackgroundVisibility(.hidden)` 加 `scrollEdgeEffectHidden` 关掉，顶部与画布同色。

## Verification

- core 单测（临时仓库）：
  - 解析出文件、段和行号；
  - 拒绝一段只回退这一段；
  - 这一段已经被别的改动挪动过时，再拒绝会标为过期；
  - 全部接受后这一轮变为已接受；
  - 评论只发送一次；
  - “自上次已看”的范围正确。
- 宿主端到端：恢复一轮后，读取它的 diff、写评论、拒绝一段，文件正确回退，“已拒绝 1 处”计数正确；下一条消息带上拒绝提醒；评论合成一条消息发出。
- Swift：解码、过大文件折叠、状态文字。
