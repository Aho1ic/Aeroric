# Agent Note: PDF 阅读与摘录带回输入框（Q-R4 第一批）

Status: implemented

## Problem

路线复核的 Q-R4 定下"通用 PDF 阅读 + 批注带回输入框"排在 R3 之后，LaTeX 排版对比等明确要写论文时再做（[路线复核](../../proposed/architecture/2026-11-02-roadmap-recheck.md)）。用户常一边读论文、一边让 Agent 照着改训练代码，此前 Aeroric 里却看不了 PDF：

- 中栏预览遇到 `pdf` 和图片，直接显示"此类型尚无已接入的只读查看器"；
- 宿主的文件读取只回传文本，拿不到 PDF 的字节；
- 预览打开时会话页被盖住，输入框草稿只在会话页自己的状态里，别的面板没法往里放东西。

用户 2026-11-13 说"全部按推荐"，第一批：

- 中栏用 PDFKit 打开本机项目和链接文件夹里的 PDF，能翻页、能搜索；图片顺带接上，只看；
- 选中一段，可以写一句批注，"加到输入框"；
- 批注不单独保存，变成输入框里的文字，发出去以后留在会话记录里；不写进 PDF；
- 追加到当前会话的输入框，不自动发送；
- 不给 Agent 加读 PDF 的工具；
- 远程项目照旧显示不支持，也不做"打开任意 PDF"。

## Decision

**预览：本机文件直接读，不经宿主**（`ProjectResourceBook.loadPreview`）

- `ResourceMedia.kind(forExtension:)` 认 `pdf` 和常见图片（png、jpg、gif、webp、heic、tiff、bmp）。这几类先于宿主读取处理，宿主不可用时也能看。
- 文件在哪（`ResourceMedia.localURL`）：
  - 链接文件夹的节点（`@linked:<路径>|<相对路径>`）直接换成绝对路径；
  - 其他文件只有项目目录在这台 Mac 上存在时，才拼成本机路径；
  - 找不到本机目录就当远程项目，显示"远程项目的 PDF 和图片还不能在这里查看"；
  - 本机路径不可读，显示"文件不在了，或没有读取权限"。
- 成功时 `previewMedia` 存类型、URL 和一个每次读取都换的 `revision`，`previewText` 留空。"重新读取"会换 revision，查看器随之重建。切换标签会清掉旧的 `previewMedia`。
- zip、字体仍是"尚无已接入的只读查看器"。

**PDF 阅读**（`Shell/PDFReader.swift`）

- `PDFReaderView` 包一个 PDFKit 的 `PDFView`：单页连续滚动、自动缩放。
- 顶栏：
  - 胶囊搜索框，回车搜索，再回车跳到下一个；显示"3 / 12"或"没有找到"；
  - 右侧显示"第 x / N 页"。
- 加密或损坏的 PDF 显示原因，不崩。
- 选中文字后底部出现摘录栏：选中内容的前两行、所在页、批注胶囊输入框和"加到输入框"按钮。
- 前面没有会话时，摘录栏只提示"先打开一个会话"，不给按钮。
- 选中文字和页码靠 `PDFViewSelectionChanged`、`PDFViewPageChanged` 通知更新。观察者挂在协调器上，跟着视图一起释放。

**摘录的文字格式**（`PDFExcerpt`）

- PDF 抽出的文字在句子中间断行，所以先接回去：
  - 中日文字符之间不加空格；
  - `assign-` 加小写开头的下一行，接成 `assignment`；大写开头的保留连字符，因为是复合词；
  - 空行保留为段落分隔，多个空格合成一个。
- 超过 4000 字截断，并写明"只带了前 4000 字"。
- 格式是引用块，加来源和页，再加批注：

  ```
  > 原文
  >
  > —— `papers/tal.pdf` 第 3 页

  批注
  ```

- 来源写项目内的相对路径；链接文件夹里的文件写绝对路径，Agent 要读全文时能直接找到。
- 页码按第几页写；印刷页码不同时加括号，例如"第 14 页（页码 12）"；跨页写"第 3–4 页"。

**带回输入框**（`ComposerInbox`）

- 一个全应用共用的 `@Observable` 收件箱，按会话 id 存待放进输入框的文字。由 `AppServices` 持有，经 SwiftUI environment 传下去。
- `TaskWorkspaceView.excerptTarget`：当前选中的会话是结构化会话、不是讨论时，摘录发到它；否则为 nil。
- `LiveSessionView` 监听自己那份的条数。有新内容就全部取走，空一行追加到草稿后面，从不发送。
- 会话页在预览底下只是隐藏，并未销毁，所以摘录会马上进草稿。即使会话页还没出现，收件箱也会留着，等它出现时再取。

## Alternatives considered

- **批注存进 core，下次打开还在**：适合反复回看同一篇论文。没有采用：要加存储和 RPC，按"业务真相在 core"还得做版本冲突。第一批的批注只是给 Agent 的话，发出去之后会话记录就是存档；真需要回看时再做。
- **批注写进 PDF 文件**（PDFKit annotation）：别的阅读器也能看到。没有采用：会改用户的文件，而且论文 PDF 常常是下载来的、只读的。
- **加到输入框后直接发送**：少点一下。没有采用：用户往往要连摘几段、再补一句要求，自动发送会把半截想法发出去。
- **给 Agent 加 `read_pdf` 工具**：Agent 能自己读全文。没有采用：摘录已经带了原文、路径和页码；Claude 能直接读 PDF，Codex 也能用 shell 抽取文字。按实际用下来再决定，放第二批。
- **经宿主读 PDF 字节**，远程项目也能看：要给 `files.read` 加二进制通道和大小上限。没有采用：第一批只为本机读论文，远程项目照旧显示不支持。
- **用系统 Quick Look 打开**（文件树里按空格已经能看）：不用写查看器。没有采用：Quick Look 拿不到选中的文字，也就做不了摘录。

## Consequences

- 收益：
  - 本机项目和链接文件夹里的 PDF、图片可以在中栏直接看，不用离开 App；
  - 读论文时摘几段、各写一句批注，回到会话就是一条带出处的消息草稿；
  - 收件箱是通用通道，以后别的面板（代码预览、Wiki）想往输入框放东西可以复用。
- 代价：
  - 本机文件绕过了宿主的读取边界：查看器直接读磁盘，靠的是路径来自文件树，而文件树本身受宿主约束；
  - 批注不保存，关掉预览、没加到输入框的批注就丢了；
  - 远程项目看不了 PDF 和图片；
  - 只在结构化会话里能带回，旧式终端会话和讨论不接收。
- 待目检（已记进路线图的待目检清单）：
  - 打开 PDF、翻页、搜索；
  - 选中、写批注、加到输入框，回到会话看草稿；
  - 没有会话时的提示；
  - 图片预览；
  - 远程项目和损坏 PDF 的提示。

## Testing

- `PDFExcerptTests`：
  - 断行接回（英文连字符、中文、段落、多余空格）和超长截断；
  - 页码文字（同页、印刷页码不同、跨页）；
  - 引用块格式，空批注不多出空段；
  - 收件箱按会话分开、取一次就清、追加到草稿；
  - 本机 PDF 和图片不经宿主就能打开，切换标签清掉旧查看器，文件不在、远程项目各自给出原因，假宿主一次都没被调用；
  - 链接文件夹的路径换成绝对路径。
- 原有的 `ProjectResourceBookTests`（远程图片仍不支持、不回退到宿主读取）和 `FileTabsTests` 照常通过。
