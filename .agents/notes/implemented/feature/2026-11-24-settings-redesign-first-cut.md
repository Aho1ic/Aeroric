# Agent Note: 设置界面重新设计：分组、搜索、平铺行、新页面

Status: implemented

## Problem

用户 2026-11-24 通过了[设置界面的方案](../../proposed/feature/2026-11-24-settings-redesign.md)，其余“都按照推荐”。方案分五个阶段，三处待用户决定，都按推荐处理：
- 阶段 1 照方案的结构做；
- 通知、快捷键在阶段 2 做；
- 远程写文件的开关在设置里给出界面，默认关，打开要确认。

动手前核对到（`main@083097c4` 加上本批未提交的改动）：
- **远控页拿不到宿主：** `RemoteStore` 由 `AppServices` 用 `RemoteStore(client: nil)` 建出来，从没接过宿主连接。主窗口侧栏的“远控”页即使放出来，也只会写“不可用”。
- **通知：** 只有一种，Aeroric 不在前台时“需要你批准”（`ApprovalNotificationGate`），没有开关。
- **远程写文件：** 宿主的 `remote.updateConfig` 不收 `allow_file_writes`，状态里也不报它。要给出开关，得先改宿主方法和 `contracts/` 里的协议文档。
- **存储、Git、工作副本：** 宿主没有算目录大小的方法，也没有这几项设置。

## Decision

这次做方案的阶段 1，加上阶段 2 到 5 里不需要改宿主的部分。

**结构（`SettingsPane`、`SettingsGroup`）：**
- **应用：** 通用、外观、通知、键盘快捷键；
- **Agents：** 新会话与 Agent、旧版 Agent 清理；
- **数据与隐私：** 导入、记忆与整理、诊断；
- **集成：** 技能与扩展、参考代码库、远程与手机、宿主连接；
- **编码：** Git、工作副本；
- **关于**（不分组，放最底下）。

每页有标题和一行副标题（`subtitle`）。

**搜索（`SettingsIndex`）：**
- **索引：** 每页的行都登记标题和一串关键词。
- **匹配：** 查询拆成词，每个词都要在“页名 + 页副标题 + 行标题 + 关键词”里出现。隐藏的页不搜。
- **结果：** 左栏换成结果列表，每条写行标题和所在页。点一条，打开那一页，滚到那一行，用强调色闪 1.4 秒。
  - 定位靠 `SettingsRow` 的 `anchor`：默认是标题；标题会变的行，单独给一个固定的名字，比如“空闲后释放 Agent 进程”；
  - 闪的那一行由环境值 `settingsHighlight` 告诉 `SettingsRow`。
- **没有命中：** 写“没有找到”。

**平铺行：**
- `SettingsCard` 去掉底色和边框，只留灰色小标题；`SettingsRow` 每行上面一条细线；
- 两者的接口没变，各页不用改调用，参考代码库页也跟着变；
- 窗口改为 920×640，最小 860×560。左栏 220pt，内容列最宽 680pt，居中。

**新页面：**
- **通知：** 三个开关，存在 `UserDefaults`（`NotificationPreferences`）：
  - “需要我批准时”（默认开，原有行为）；
  - “会话做完或失败时”（默认关）：Aeroric 不在前台时，会话从运行中、等你回应或排队变成完成或失败，就发一条通知（`FinishedNotificationGate`）；
  - “提示音”（默认开）。
- **键盘快捷键：** 列出菜单和输入框里现有的快捷键，只读，写明“快捷键现在不能改”。
- **新会话与 Agent：** 原“Agents”页，多一行“每个项目记住新会话的选择”，说明上一步做的记忆和 Harness 换算。
- **记忆与整理、技能与扩展：** 各一行，按钮跳到主窗口的“记忆”“扩展”页（`settingsOpenPage`）。技能页另列 MCP 服务器、Hook、插件，标“即将支持”，和“扩展”页的说法一致。
- **诊断：** 导出诊断报告，从“关于”页挪过来。
- **远程与手机：**
  - `RemoteStore` 加 `attach(client:)`，宿主连上时接上 `RemoteClient`；
  - 页面就是原来写好的 `RemoteAccessSettingsView`。它是一个自带滚动的分组表单，所以这一页不套外层滚动；
  - 主窗口侧栏不列“远控”（`WorkspaceSection.listed`）。
- **Git、工作副本：** 只列出将来会有的设置，标“即将支持”，不放没有作用的控件。

## Alternatives considered

**这次连同宿主一起做：存储大小、远程写文件开关、Git 和工作副本设置。** 没做：
- 存储大小要一个新的宿主只读方法；
- 远程写文件开关要改 `remote.updateConfig` 和状态的协议文档（契约检查会拦）；
- Git 和工作副本设置宿主还没有。

这些各自是一次宿主改动，下一步分别做。

**外观里的对比度和配色预设。** 没做：要给 `AeroricColor` 的每个颜色加高对比度和自定义的取值，是一次设计系统层面的改动，单独做。

**搜索直接扫视图里的文字。** 没选：SwiftUI 拿不到别的视图里渲染出来的文字。用一张索引，再用测试盯住常用词。

## Consequences

- **收益：**
  - 设置按用途分组，能搜，每页说明它管什么；
  - 远控页第一次能真正用上；
  - 有了通知开关和快捷键列表。
- **局限：**
  - 索引要和行一起维护，新加一行要记得登记，否则搜不到；
  - 对比度、配色预设、存储、远程写文件开关、Git 和工作副本设置还没做；
  - 界面没有目检，所有设置页的样子都变了，要整体看一遍。
- **验证：**
  - Swift 新增 `SettingsRedesignTests` 4 个测试：
    - 每页有标题、副标题，按组排列；
    - 搜索的常用词各落到对的行，隐藏的页不搜，锚点不重复；
    - 完成通知只在后台、从运行状态变成完成或失败时发；
    - 快捷键列表有 ⌘N、⌘K、⌥↩。
  - MacBook 上 AeroricKit 全部测试都过（UI 1061 个，跳过 1 个）；App 层要在完整构建里编译。
