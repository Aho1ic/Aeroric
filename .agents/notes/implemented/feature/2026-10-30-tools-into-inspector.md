# Agent Note: 文件与 Git 并入会话右侧栏，去掉 IDE 与 Agent 工具页

Status: implemented

## Problem

左侧栏「工具」分组里的文件页、Git 页，和会话右侧栏的「文件 / 改动 / Git 日志」做的是同一件事：用户不知道该去哪边改文件、看改动。IDE 页早在 2026-10-23 就定为取消（backlog §2.1），入口却一直挂着「即将推出」。Agent 工具页的 8 个区块全是空壳：`ExternalProtocolStore` 从没接过数据，会话控制要用的目标会话从没赋值。owner 2026-10-30 讨论后全部按推荐定案（Trellis 任务 `10-30-tools-into-inspector`）。

## Decision

**侧栏**
- 去掉 文件、Git、IDE、Agent 工具 四个入口。数据库、笔记 在做出来前不列出（`WorkspaceSection.listed`），「工具」分组整组不显示，命令面板同步。
- 旧的选择（如 `section.git`）解析不到，回落到任务页。

**右侧栏分页**：详情 / 文件 / Git。「改动」和「Git 日志」合并为 Git，标题带改动数。

**文件树写操作**
- 顶部「新建文件」「新建文件夹」：建在选中文件所在的目录，没有选中时建在根目录。
- 右键菜单：新建文件、新建文件夹、重命名、快速查看、在访达中显示、复制路径、移到废纸篓…（先确认）。
- 名字在树里对应位置的胶囊输入框里填，回车确认，Esc 取消。失败原因显示在树上方，单行不换行。
- 写操作沿用 `applyFileEdit`，改为返回错误文字；成功后重新读取那一层目录。

**标签跟随**（`ProjectResourceBook.followEdit`）
- 重命名：路径等于旧路径、或在旧文件夹里的标签，连同草稿、滚动位置一起改到新路径。
- 移到废纸篓：关闭这些标签。前台标签变了就重新读取。

**关联文件夹**
- 原来只有文件页能看到，现在列在右侧栏树的根目录末尾。读取时用 `LinkedFolderPath.request` 映射到宿主。
- 只读：没有写菜单，标签不能保存。快速查看、在访达中显示用 `LinkedFolderPath.absolute` 得到的本机路径。

**Git 窄栏**（`GitSidebarPanel`）
- 第一行：分支胶囊菜单（切换、新建、发布），以及 获取、↓N、↑N 或「发布」。都先确认。
- 下面依次是：提交框（生成 / 提交 N 个文件）；已暂存、未暂存两组；默认折叠的贮藏、历史（历史只列提交）。
- 点文件在中间栏打开 diff 标签。
- 单文件按钮在悬停时出现，选中行上一直显示，右键菜单也能用。2026-10-30 的验收报告指出只靠悬停很难点到。

**删除**：Git 整页与 `GitDiffText`、`loadGitDiff`；文件整页、`FileTreeStore`、`loadFiles`；Agent 工具页及它的两个 store、能力探测；IDE 页的分支。宿主 IDE 后端保留，留给后面的「回合结束自动检查」。

## Alternatives considered

- **保留两套**：功能重复，验收时也分不清该看哪边。
- **diff 放在右侧栏里内联展开**：栏宽约 300 点，放不下 diff；中间栏已有带行号的 diff 标签。
- **新建时在树上方弹表单**（文件页的做法）：owner 选的设计稿是在树里就地输入。
- **只隐藏 Agent 工具入口、保留代码**：页面没有任何真实数据，留着只会误导后来的人。

## Consequences

- `ProjectResourceBook` 里旧的「改动」读取（`loadGit`、`toggleInlineDiff`、`ResourceListSection`）已经不会再被触发，暂时保留，等确认没有别的读者后再删。
- 右侧栏的 Git 分页和以前的 Git 页一样，用的是全 App 共用的 `GitStore`。两个窗口同时显示不同项目的 Git 时，后读取的会覆盖先读取的。
- 测试：标签跟随重命名和废纸篓（3 个）、关联路径映射与根目录条目（2 个）。侧栏入口在 App target，没有单元测试，靠目检。
