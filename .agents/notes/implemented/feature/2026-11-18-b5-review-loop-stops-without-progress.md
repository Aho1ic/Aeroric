# Agent Note: B5 审查循环没有进展就停

Status: implemented

## Problem

[调研落地批次 B](../../proposed/feature/2026-11-15-adoption-b-acceptance-and-artifacts.md) 的 B5。审查循环（[审查门禁](../feature/2026-11-08-review-gate-flags.md)）只在轮数到 `MAX_ROUNDS`（3）时停下。

审查者每轮提同样的阻断问题，作者每轮交回同样的改动时，循环也要把轮数耗完：

- 每多一轮，都多花一次审查模型和一次作者回合；
- 最后交给用户的理由是"已审查 3 轮仍有阻断问题"，没说明其实是在原地打转。

## Decision

- 每轮作者答复、改动已知、准备进入下一轮时，记下两个指纹：
  - 这一轮的阻断问题（`Severity::Blocker`）：
    - 有文件和行号的，归为"文件:行"；
    - 只有文件的，归为文件加去掉空白和标点的原文；
    - 都没有的，只取去掉空白和标点的原文；
    - 排序去重。审查者换个说法指同一处，仍是同一个问题。
  - 作者答复后的树对象 id（`TurnDiff.after`）。
- 两个指纹都和上一轮相同：停下，状态记"已交给你"（`Escalated`），原因写"上一轮和这一轮的阻断问题相同，改动也没有变化，交给你决定"。
- 只有问题相同、改动不同：作者还在尝试，继续。
- 只有改动相同、问题不同：继续一轮再判。
- 改动的树对象 id 未知（为空）时不判，照常继续。
- `MAX_ROUNDS` 保留为上限。
- 指纹存在循环的持久化状态里（`progress`），宿主重启后接着判。

## Alternatives considered

**只比问题，不比改动。** 最强的理由是实现更简单。没选：作者在认真改、审查者一时还不满意，也会出现问题相同的两轮；这时停下会打断正常收敛。改动也没变，才说明真的卡住了。

**用模型判断两轮是否"实质相同"。** 最强的理由是能识别措辞差异更大的重复。没选：多一次模型调用，结论也不可复现；按位置和规范化原文比较，便宜、确定，覆盖了常见的换个说法。

## Consequences

- **收益**：原地打转的循环在第二个重复轮就停，省下后续轮次的模型调用，原因也写清楚了。
- **代价**：审查者对同一处提了实质不同的阻断问题、作者又恰好没改文件时，也会被判为没有进展。这时作者没改文件，交给用户本来就合适。
- **验证**：
  - `review/tests.rs` 新增两个测试：
    - `a_round_that_repeats_the_last_one_stops_the_loop`：换了措辞、同一位置的阻断问题，加上同一棵树，在第 2 轮停下；
    - `the_same_issues_with_new_changes_go_on`：问题相同但树不同，进入第 3 轮；
  - 原有的 `the_third_round_is_the_last` 照常通过（树 id 为空时不判）；
  - 卡片上已有显示停止原因的位置，界面没有改动。
