# Agent Note: 侧栏项目与会话的“更多”菜单、harness logo 与导入补扫

Status: implemented

## Problem

侧栏的项目行只有一个“新建会话”按钮，会话行只有右键菜单里的归档。用户要的操作有：重命名、改颜色、默认 Agent、分组、会话管理、移除工作区，以及会话的置顶、重命名、分叉、复制 Session ID、移除，参考 codeg 与 deepseek-harness。

会话行左边是 SF Symbol，看不出会话用的是哪个 harness。

导入的会话比 codeg 少得多：Codex 已归档的会话没扫；用户在导入选择框里取消勾选的会话被记为“不导入”，之后看不到入口。

## Decision

- **两个 ⋯ 按钮**：项目行在加号左边、会话行在状态点左边，悬停才显示。会话行的 ⋯ 叠放在行按钮之外，点它不会同时打开会话。右键菜单与 ⋯ 菜单内容相同。
- **项目菜单（S1–S5）**：
  - 重命名：只改 Aeroric 里显示的名字（`name`），留空就恢复为文件夹名；
  - 修改颜色：给最左边的文件夹图标着色，不另加色点；
  - 设置默认 Agent：写进项目记录的 `defaultAgent`（一个配置 id），这个项目里的新会话草稿默认选中它；
  - 移动到分组：复用 core 的 `group` 字段，侧栏按分组显示小标题；
  - 会话管理：弹窗列出全部会话，包括已归档的，可以按 harness 筛选、多选后批量操作；
  - 从 Aeroric 移除工作区：只删列表里的记录，并在 `removed-projects.json` 里按位置记下原 id，重新打开同一文件夹（本地或 SSH）时沿用原 id，会话随之回来。
- **会话菜单（S6–S7）**：
  - 置顶：`task.set_starred`，写到宿主；之前只是窗口里的临时翻转；
  - 重命名：`task.rename`，写 `name`，显示标题优先用它；
  - 分叉：`task.fork` 新建一个待办任务，会话 id 记为占位 `fork:<源 id>`；它第一次启动时，Claude 用 `--resume <源> --fork-session`，Codex 用 `thread/fork`，Agent 返回的新 id 会替换占位；omp 与导入会话不支持，菜单项置灰并说明原因；
  - 复制 Session ID：取所属家族的会话 id；导入会话的 id 从文件名读取；
  - 移除：`task.delete` 只删任务行，transcript 不动，已置顶的会话会保留。
- **harness logo**：用 App 资源里的单色模板矢量图（`HarnessClaude/Codex/OMP/DSH`），无边框，按文字颜色着色。任务按 `sessionFamily` 判断 harness，导入会话按 agent；不认识的 agent 仍用原来的符号。
- **导入（S8）**：Codex 补扫 `archived_sessions`，扫到的会话默认显示为已归档；用户取消归档会记进 `prefs.unarchived`。`imports.status` 返回每家被排除的数量，设置页显示“已排除 N 个 · 重新选择”。
- **侧栏可靠性**：项目列表读取失败时每 3 秒重试，最多 20 次，不再静默留空；列表成功后，宿主已没有的项目和任务会从侧栏清掉。实时会话轮询连续失败 2 次才提示，提示里带上错误原因，同时写日志。

## Alternatives considered

- **分叉时新增任务字段、穿过 LaunchRequest 一路传到驱动**：要改协议结构和全部构造点。用会话 id 占位前缀只改两个驱动的恢复分支，影响面小；代价是占位 id 在第一次启动前不是真 id。选了前缀。
- **移除工作区时连同任务目录一起删**：违反“移除不删数据”的原则，误操作也无法恢复。否掉。
- **“重命名”和“设置别名”分开做两项**：对文件夹项目来说两者效果相同。合并成一项。
- **一次接入 codeg 的全部二十来个解析器**：工作量大，且用户没有指明常用哪几家。先补 Codex 已归档会话和“重新选择”入口，其余等用户挑选后再接。

## Consequences

- **收益**：
  - 项目与会话的常用操作都在侧栏一处完成；
  - 移除可逆，不碰磁盘文件；
  - 会话来源一眼可辨；
  - 导入数量与磁盘上的实际会话数对得上（排除的除外）。
- **代价与已知上限**：
  - 标签与关联文件夹留到第二批；
  - Codex 的 `thread/fork` 依赖 app-server 支持该方法，版本太旧时分叉会报错；
  - omp 不能分叉；
  - 导入仍只支持 Claude 与 Codex。
